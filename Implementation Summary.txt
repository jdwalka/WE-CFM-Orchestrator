Implementation Summary
1. Critical Audit Corrections & Traps Addressed
dYdX: Migrated deprecated v3 endpoints to v4 Indexer (https://indexer.dydx.trade/v4/orderbooks/perpetualMarket/{ticker} and /v4/historicalFunding/{ticker}) with zero auth overhead.
OKX: Strictly enforced apex domain routing to https://www.okx.com/api/v5/... to eliminate 301/308 redirects that drop headers or cause CORS preflight failures in fetch.
Bybit: Split linear orderbook and tickers polling; parsed fundingRate and nextFundingTime strictly from /v5/market/tickers.
Deribit: Corrected invalid path to GET /api/v2/public/get_order_book?instrument_name={sym}-PERPETUAL&depth=20 with explicit depth param.
Binance: Enforced lowercase /fapi/v1/... and integrated /fapi/v1/fundingInfo to capture funding clamp interval tightening (< 8h) and cap expansion (> 0.75%) feeding burst_pressure.
Hyperliquid: Replaced rejected GET calls with multiplexed single POST https://api.hyperliquid.xyz/info fetching { type: "metaAndAssetCtxs" } and { type: "predictedFundings" }.

Bybit HTTP 403 (Cloudflare WAF): Enforced browser TLS headers (User-Agent, Accept-Language, sec-ch-ua) with automatic fallback to the Rust proxy server (127.0.0.1:3010/bybit).
